使用说明与帮助

            

              如何调用 REST API
              
使用标准 HTTP 客户端携带 Authorization: Bearer <Token> 发起 GET 请求：

              

                
                

              

            

            

              如何连接 MCP 客户端
              
在 Claude Desktop 的 claude_desktop_config.json 或 Cursor 的 MCP 设置中添加上述通用 JSON 配置即可。MCP 采用 Streamable HTTP 传输协议，直接向 /mcp 端点发起带 Bearer Token 的 POST 请求。

            

            

              如何测试连接
              
可以向 /api/ext/v1/health 发送 GET 请求，或向 /mcp 发送 ping JSON-RPC 请求检验凭证有效性。

            

            

              如何禁用或撤销凭证
              
在上方 Token 列表中点击「禁用」可临时冻结凭证；点击「撤销」将永久废除凭证，废除后所有请求将立即被系统拒绝。

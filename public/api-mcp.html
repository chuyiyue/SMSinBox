接口端点

              
以下端点均基于上方 API Base URL，全部使用 GET 方法并携带 Authorization: Bearer <Token>。

              

                

                  GET
                  /health
                  连通性检查，验证 API 与 Token 有效。
                

                

                  GET
                  /me
                  当前 Token 详情（权限、设备范围、有效期）。
                

                

                  GET
                  /messages
                  短信列表，支持分页与 device_id / from / since / until / q 过滤。
                

                

                  GET
                  /messages/{id}
                  单条短信详情。
                

                

                  GET
                  /otp/latest
                  最新验证码，可用 device_id / from / since 过滤。
                

                

                  GET
                  /otp/search
                  验证码检索，支持分页与过滤。
                

                

                  GET
                  /devices
                  授权设备列表及在线状态。
                

                

                  GET
                  /devices/{id}/status
                  单台设备在线状态与最后消息时间。

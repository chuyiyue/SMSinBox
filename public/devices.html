iOS 27 及以上
  1. 在上面新建设备，复制 Webhook URL 和 token。
  2. 下载模板后在 iPhone 上打开。若系统拒绝未签名文件，按下面的手动步骤新建，或等文档里的 iCloud 链接（尚未发布就先用手动步骤）。
  3. 导入时填写 Webhook URL 和设备 token。不要把 token 发给别人。
  4. 打开「快捷指令」→「自动化」，展开这条快捷指令的触发器。
  5. 打开自动化开关，关闭「运行前确认」，有「锁定时允许运行」就打开它。
  6. 全部短信选「信息包含一个空格」。没有空格的短码改用验证码模板，或额外加上「验证码」和 code。
  7. 保存。用另一台手机发一条含「验证码 123456」的短信，或点设备旁边的「发送测试消息」。
iOS 26 及以下
  1. 复制 URL 和 token。
  2. 打开「快捷指令」→「自动化」→ 点「+」→「信息」。
  3. 发件人可以选任何人。条件选「信息包含一个空格」，或「包含」验证码 / code。
  4. 选择「立即运行」，关闭「运行前询问」。
  5. 把下载的快捷指令加进这个自动化。系统拒绝未签名文件时，改用手动步骤。
  6. 保存。手机重启后要先解锁一次，自动化才会继续跑。
手动添加「获取 URL 内容」
  1. 按上面对应系统版本新建「信息」自动化，并设好触发条件。
  2. 添加「文本」，内容填 Webhook URL。再添加一个「文本」，内容填设备 token。
  3. 再添加「文本」，内容是 Bearer 加上 token 那个文本的输出。
  4. 添加「获取 URL 内容」。URL 选第一个文本，方法 POST，打开显示标头。
  5. 标头 Authorization 选 Bearer 文本，Content-Type 填 application/json。
  6. 请求体选 JSON：from 用快捷指令输入的发件人（Sender），空的话改成自动化的「发件人」；content 用快捷指令输入；timestamp 用当前日期；device 填 iOS。
  7. 可选「显示通知」，标题 SMSinBox，正文「已转发」。关闭运行前询问后保存。

共享来的自动化默认是关闭的。手机需要开机并联网，只转发文本，不支持彩信。分版本步骤、常见问题和限制写在仓库的 docs/ios-setup.md。

推送

短信先写入收件箱，再推送到已启用的渠道。某个渠道失败不会丢掉短信。

          可选 HMAC
          
创建设备时如果填写了签名密钥，之后每次上报都必须带 X-Timestamp（Unix 秒或毫秒）和 X-Signature。签名是 HMAC-SHA256(X-Timestamp + 原始请求体, secret) 的十六进制，时间窗口 ±5 分钟。SmsForwarder 和快捷指令的默认配置不会签名，密钥请留空。

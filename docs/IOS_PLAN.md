# iOS 接入策划

## 目标
网页设备页生成 Webhook URL + Token，用户 1–2 分钟内完成 iOS 快捷指令配置。主路径为预置快捷指令，备选为手动搭建。明确告知 iOS 限制。

## 预置快捷指令
- 交付：shortcuts/SMSinBox-iOS.shortcut（可下载），文档维护 iCloud 分享链接；网页设备页加“下载 iOS 快捷指令”按钮和配置复制区。
- 触发器：收到消息时，条件 Message contains 一个空格；另提供“仅验证码关键词”版本。
- 动作：获取 URL 内容，POST，Header `Authorization: Bearer <Token>`，JSON body {from: 发件人, content: 消息内容, timestamp: 当前日期, device: "iOS"}；可选显示“已转发”通知。
- 导入问题：Webhook URL、设备 Token。

## 用户流程
iOS 27+：设备页创建 iOS 设备并复制 URL/Token → 下载或打开 iCloud 链接添加 → 填写导入问题 → 展开触发器 → 打开自动化开关 → 关闭“运行前确认” → 开启“锁定时允许运行” → 保存 → 发测试短信。
iOS 26 及以下：自动化标签页 → + → 信息 → 设置条件 → 立即运行。
备选：纯手动搭建，文档分 iOS 26/27 给出完整步骤，适合自定义发件人或关键词。

## 网页端
设备详情页“iOS 配置”区：复制 URL、复制 Token、下载 .shortcut、可折叠的配置步骤；可选“发送测试消息”按钮。

## 文档
README 增加“iOS 接入”章节；docs/ios-setup.md 写分版本步骤、常见问题（自动化没开、重启后需解锁、短码用关键词）、限制说明。

## 里程碑
- MVP：手动搭建文档（iOS 26/27），按文档能上报一条短信。
- v1：预置 .shortcut + 网页下载入口 + 导入问题，新用户 2 分钟内完成配置。
- 后续：多版本快捷指令（全量 / 仅验证码）、配置校验提示、一键更新模板。

## 已知限制（文档显著位置）
共享快捷指令的自动化默认关闭需手动开启；必须有匹配规则（空格最接近全量）；需开机联网，重启后解锁一次；仅文本无 MMS；短码短信建议加关键词规则（验证码、code）。
